    Favoritos

      Minhas progressões

      Separe os acordes com vírgula, espaço ou |. Ou use “＋ Progressão” no diagrama de cada acorde.

        Progressões para estudo

        Toque para ensaiar (e use “▶ Tocar progressão” para ouvir sozinha). Toque numa música para ir ao tom original dela. “Copiar” leva a progressão para o formulário, para você criar a sua a partir dela.

        Ritmo

        · versões simplificadas para quem está começando; o ritmo “de verdade” tem variações de cada região e músico.

          Como tocar

            76 BPM

            . Os instrumentos padrão do ritmo já vêm ligados: toque para mutar ou ligar (dá para mudar tocando). Desligue “Som do instrumento” para você fazer a parte do violão.

              Ajustes

              Tema

              Só contagens de telas e ações (ex.: “tocou um acorde”), sem cookies nem dados pessoais — ajudam a melhorar o app.

              Backup

              Favoritos e progressões ficam só neste navegador. Exporte um arquivo para guardar uma cópia ou levar para outro aparelho.

              Área de perigo

              Apaga favoritos, progressões e preferências deste aparelho. Não dá para desfazer.

              Instalar no iPhone/iPad

              1. Toque em Compartilhar ⬆︎ na barra do Safari.
              2. Escolha Adicionar à Tela de Início ＋.
              3. Confirme em Adicionar. O app abre em tela cheia e funciona offline.
