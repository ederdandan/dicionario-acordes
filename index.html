            Área de perigo

            Apaga favoritos, progressões, tablaturas e preferências deste aparelho. Não dá para desfazer.

            Instalar no iPhone/iPad

            1. Toque em Compartilhar ⬆︎ na barra do Safari.
            2. Escolha Adicionar à Tela de Início ＋.
            3. Confirme em Adicionar. O app abre em tela cheia e funciona offline.

            Tablatura salva — só neste aparelho

            Ela fica guardada apenas neste navegador; não vai para nenhuma nuvem nem conta. Se você limpar os dados do navegador, desinstalar o app ou trocar de aparelho, ela se perde. Exporte um arquivo para guardar uma cópia — depois é só usar ⚙ Ajustes → Importar backup.
